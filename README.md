Everything I make is **local-first**. No telemetry, no phone-home.

## What I've shipped

**🪂 [Wingman MCP](https://github.com/adeoluwaadesina/wingman-mcp)** · `pip install wingman-mcp`
A persistent, interactive plan panel that lives inside your Claude conversation. You tick checkboxes, Claude ticks tasks, state syncs live. *Sits beside you. Doesn't fly the plane.*

**🧬 [Genesis MCP](https://github.com/adeoluwaadesina/genesis-mcp)**
A self-extending MCP server. It ships with exactly one tool: a tool that creates other tools, live, in the middle of your session.

**📖 [Storyvive V4](https://github.com/adeoluwaadesina/Storyvive-V4)**
Canon extraction for stories, so AI stops forgetting your characters halfway through chapter three.

**💵 [Fake Naira Detector](https://github.com/adeoluwaadesina/Fake-Naira-Detector-using-Deep-Learning)**
Deep learning applied to a very real Nigerian problem: spotting counterfeit banknotes.

**👠 [Zeli Models](https://github.com/adeoluwaadesina/zeli-models)** · **🏗️ [Groundwork NG](https://github.com/adeoluwaadesina/groundwork-ng)**
Production client work and civic-tech frameworks, because variety keeps it fun.
